# Record of Processing Activities

**Project:** AI-Assisted Education System for Government Schools in Karnataka (IIT Dharwad × DSEL)
**Version:** 1.0 (2026-06-27) — draft, maintained by IITDH (Processor)
**References:** DPDP Act 2023; MoU Clause 9

---

| Field | Detail |
|---|---|
| **Processing activity** | Digitisation and annotation of handwritten answer scripts to train/evaluate OCR & assessment models |
| **Data Fiduciary** | DSEL, Government of Karnataka |
| **Data Processor** | IIT Dharwad |
| **Categories of data principals** | School students, Grades 8–10 (predominantly minors) |
| **Categories of personal data** | Handwritten answer scripts; student name and roll number (identifiers) — **redacted before annotation** |
| **Special considerations** | Children's personal data (DPDP §9 / Rule 10) |
| **Source of data** | DSEL — Office of the Commissioner for School Education, Dharwad (handover via Shri Ashok Kumbar) |
| **Purpose** | Development, evaluation and improvement of the project's handwriting-recognition (OCR) and assessment system |
| **Lawful basis** | Department authorisation + Fourth Schedule (educational/research) exemption + minimisation — see `lawful-basis-note.md` |
| **Recipients / access** | Authorised IITDH project members (in-house) under confidentiality undertakings; future sub-processors only under DPA |
| **Storage location** | IIT Dharwad PowerEdge server (intranet), India; encrypted backup in India (GCP `asia-south1`) |
| **Cross-border transfer** | None — India only (MoU Clause 9.5) |
| **Volume** | ~5,000 pages (initial); pilot uses a subset |
| **Retention** | Project term; raw scans 5 years; then return + secure delete (MoU 9.4) — see `retention-and-deletion.md` |
| **Security measures** | See `security-measures.md` |
| **Status** | Experimental pilot, pending MoU execution |

> Update this record whenever the purpose, categories, recipients, storage, or volume change (e.g. when additional scripts are received or external annotators are engaged).
